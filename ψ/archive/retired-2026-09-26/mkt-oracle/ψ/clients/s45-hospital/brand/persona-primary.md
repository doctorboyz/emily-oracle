## Persona A: "ส้ม" — First-Time Rhinoplasty

### Profile
| Field | Value |
|-------|-------|
| อายุ | 22-30 |
| เพศ | หญิง 80% |
| อาชีพ | พนักงานออฟฟิศ, ฟรีแลนซ์, เจ้าของธุรกิจออนไลน์ |
| รายได้ | 25K-60K/เดือน |
| การศึกษา | ปริญญาตรี |
| Location | กรุงเทพฯ และปริมณฑล |

### Goals
- เสริมจมูกครั้งแรก — อยากได้ทรงเกาหลีธรรมชาติ
- กลัวเจ็บ กลัวผิดพลาด กลัวจมูกเบี้ยว
- ต้องการข้อมูลเยอะๆ ก่อนตัดสินใจ

### Pain Points
- ไม่รู้จะเลือกคลินิกไหน — ตัวเลือกเยอะเกิน
- กลัวหมอไม่เชี่ยวชาญพอ
- กลัวราคาแพงเกิน budget
- เพื่อน/ครอบครัวอาจไม่สนับสนุน

### Decision Journey
1. **Search** — Google/TikTok: "เสริมจมูกที่ไหนดี" "รีวิวเสริมจมูก"
2. **Compare** — ดู Before/After หลายๆ คลินิก
3. **Peer Review** — อ่านรีวิว Wongnai, Lemon8, ดู TikTok influencer
4. **Consult** — ทัก LINE ปรึกษา
5. **Decide** — จองคิวผ่าตัด

### Content ที่ใช่
- TikTok ก่อน-หลัง เสริมจมูก
- รีวิวคนไข้จริง (video)
- Q&A ตอบทุกข้อสงสัย
- เปรียบเทียบเทคนิคแบบเข้าใจง่าย
