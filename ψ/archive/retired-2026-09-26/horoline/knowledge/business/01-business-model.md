# Business Model & Monetization Ethics — รูปแบบธุรกิจที่เป็นธรรม

## Subscription Tiers (ระดับบริการ)

### Tier ออกแบบตามหลัก Ethical Monetization

| Tier | ราคา (฿/เดือน) | ฟีเจอร์ | หมายเหตุ |
|------|-------------|---------|----------|
| **Free** | 0 | ทำนายรายวัน (1 ครั้ง/วัน) ราศีทั่วไป ราศีประจำปี | ต้องมีคุณค่าจริง ไม่ใช่แค่ล่อให้ซื้อ |
| **Plus** | 99 | ทำนายรายวันไม่จำกัด ทำนายเชิงลึก 3 ระบบ Numerology ปีส่วนตัว | จุดเริ่มต้นที่เข้าถึงได้ |
| **Premium** | 199 | ทำนายทุกระบบ ทำนายเชิงลึก สรุปรายสัปดาห์/รายเดือน เลือกเนื้อหาเจาะจง | สำหรับผู้ใช้จริงจัง |
| **Pro** | 399 | ทุกอย่างใน Premium + ทำนายเชิงลึก Vedic + ทำนายเฉพาะเรื่อง + บันทึกประวัติไม่จำกัด | สำหรับผู้ที่สนใจจริงจัง |

### หลักการออกแบบ Tier

1. **Free ต้องมีคุณค่าจริง**: ไม่ใช่แค่ "ลองใช้" แต่ต้องได้ประโยชน์จริง
2. **ไม่มี Paywall ที่สำคัญ**: ฟีเจอร์หลัก (ทำนายรายวัน) ต้องใช้ได้ฟรี
3. **เพิ่มมุมมอง ไม่เพิ่มความกลัว**: Premium เพิ่มมุมมอง (หลายระบบ) ไม่ใช่เพิ่มความน่ากลัว
4. **ราคาสมเหตุสมผล**: เทียบกับค่าใช้จ่ายอื่นในไทย (กาแฟ 1 แก้ว = 70-100 บาท)

## Microtransaction Design (การซื้อแบบรายครั้ง)

### สิ่งที่ขายได้ (Ethical)

| รายการ | ราคา (฿) | หมายเหตุ |
|--------|---------|----------|
| ทำนายเชิงลึก 1 ครั้ง | 19-29 | ทำนายแบบเจาะจง 1 เรื่อง |
| เลือกระบบเพิ่ม | 9-15 | เลือกดูระบบที่ไม่มีใน Tier |
| สรุปรายสัปดาห์ | 29 | สรุปแนวโน้มสัปดาห์ |
| สรุปรายเดือน | 49 | สรุปแนวโน้มเดือน |
| ทำนายเฉพาะเรื่อง | 39-59 | ความรัก/การงาน/การเงิน/สุขภาพ |

### สิ่งที่ห้ามขาย (Unethical)

| รายการ | ทำไมห้าม |
|--------|----------|
| "แก้ดวง" / "สะเดาะเคราะห์" | สร้างความกลัวเพื่อขาย |
| "เลขเด็ด" / "หวย" | ส่งเสริมการพนัน |
| "ดวงแย่ ต้องซื้อ" | Fear-based selling |
| ใบ้คำทำนาย (cryptic hints) | บังคับให้ซื้อเพื่อรู้คำตอบ |
| Variable reward (สุ่มรางวัล) | Loot box mechanic คือ addictive design |
| Streak / Daily reward ที่บังคับ | Fear of Missing Out (FoMO) |

## Cool-down & Spending Limits (ป้องกันการใช้จ่ายเกิน)

### Cool-down Periods

```typescript
interface CoolDownConfig {
  // หลังทำนาย 3 ครั้งติด → เตือน
  consecutiveReadingsAlert: 3
  
  // หลังทำนาย 5 ครั้งติด → บังคับพัก 30 นาที
  consecutiveReadingsLimit: 5
  
  // หลังพัก → แสดงข้อความ "ดาวชี้ว่าคุณทำนายเยอะมาก ขอแนะนำให้พักสักหน่อย"
  coolDownMessage: 'ดาวชี้ว่าคุณทำนายเยอะมาก ขอแนะนำให้พักสักหน่อย 🌟'
  
  // หลังใช้จ่ายครบ 500 บาท/วัน → บังคับพัก 24 ชั่วโมง
  dailySpendingLimit: 500
  
  // หลังใช้จ่ายครบ 2,000 บาท/เดือน → แจ้งเตือน + บังคับพัก
  monthlySpendingAlert: 2000
}
```

### Take a Break Feature

เมื่อผู้ใช้ทำนายติดต่อกันเกินไป แสดงหน้า "Take a Break":

```
🌟 คุณทำนายไปแล้ว X ครั้งวันนี้

ดาวบอกว่าถึงเวลาพักแล้ว
ลองกลับมาใหม่พร้อมกับพลังงานที่สดใสกว่าเดิมนะ

[พักเลย] [ทำนายต่อ] ← ปุ่มนี้เล็กกว่า ไม่โดดเด่น
```

## Pricing Psychology (จิตวิทยาราคา — ใช้อย่างเป็นธรรม)

### ใช้ได้

| เทคนิค | ตัวอย่าง | เหตุผล |
|--------|---------|--------|
| Anchoring | แสดงราคา Pro ก่อนแล้วค่อยแสดง Plus | ตั้งค่า reference สูง |
| Decoy effect | มี 3 Tier ให้เลือก | ทำให้ตัวกลางดูคุ้ม |
| ราคาจบที่ 9 | 99, 199, 399 | เป็นที่นิยม ไม่หลอก |
| Annual discount | จ่ายรายปีลด 20% | สนับสนุนการสมัครระยะยาว |
| ทดลองใช้ฟรี | 7 วันฟรีสำหรับ Premium | ให้ลองก่อนตัดสินใจ |

### ห้ามใช้

| เทคนิค | ทำไมห้าม |
|--------|----------|
| Urgency ปลอม | "เหลือ 3 ที่นั่น!" — สร้างความเร่งรีบเทียม |
| Scarcity ปลอม | "หมดแล้ววันนี้!" — บริการดิจิทัลไม่มีจำกัด |
| FoMO | "ดวงดีวันนี้เท่านั้น!" — สร้างความกลัวว่าจะพลาด |
| Dark pattern | ปุ่ม Cancel เล็ก ซ่อน — หลอกให้กดซื้อ |
| Variable reward | สุ่มรางวัล/เนื้อหา — คือ addictive mechanic |
| Social pressure | "เพื่อนของคุณทำนายแล้ว" — กดดันทางสังคม |

## O2O Commission (Online-to-Offline)

### โมเดล

```
Horoline (Online) → แนะนำโหราจารย์/สถานที่ (Offline) → รับค่านายหน้า
```

### หลักการ

1. **แนะนำ ไม่บังคับ**: แสดงตัวเลือก ไม่กดดัน
2. **ตรวจสอบคุณภาพ**: โหราจารย์ที่แนะนำต้องผ่านการตรวจสอบ
3. **โปร่งใส**: แจ้งว่า Horoline ได้ค่านายหน้า
4. **ไม่ผูกกับการทำนาย**: ไม่ใช้ผลทำนายเพื่อขายบริการ offline
5. **รีวิวจริง**: รีวิวจากผู้ใช้จริง ไม่ใช่รีวิวปลอม

### รายได้จาก O2O

| แหล่ง | ค่านายหน้า | หมายเหตุ |
|--------|----------|----------|
| โหราจารย์ออนไลน์ | 10-15% | ผ่านการนัดหมายในแอป |
| ร้านดูดวง | 5-10% | แนะนำสถานที่ |
| คอร์สเรียนโหราศาสตร์ | 15-20% | สำหรับผู้สนใจเรียนรู้ |
| สินค้ามงคล (เลือกสรร) | 5-10% | เฉพาะสินค้าที่ผ่านการตรวจสอบ |

### ห้ามขาย

- ไม่ขายเครื่องราง ของขลัง สิ่งศักดิ์สิทธิ์
- ไม่ขายพิธีกรรมแก้ดวง
- ไม่ขายหวย เลขเด็ด
- ไม่ขายคำทำนายที่บอกว่า "ต้องทำพิธีนี้เท่านั้น"

## Revenue Model Summary

| แหล่งรายได้ | สัดส่วนเป้าหมาย | หมายเหตุ |
|------------|-------------|----------|
| Subscription | 60% | รายได้หลัก คาดการณ์ได้ |
| Microtransaction | 20% | เสริม ไม่บังคับ |
| O2O Commission | 15% | โตได้แต่ต้องผูกกับคุณภาพ |
| Other (คอร์ส, สินค้า) | 5% | เสริม |

## Ethical Monetization Checklist

- [ ] Free tier มีคุณค่าจริง (ไม่ใช่แค่ล่อให้ซื้อ)
- [ ] ไม่มี fear-based selling
- [ ] ไม่มี dark pattern (ปุ่ม cancel ชัดเจน)
- [ ] Cool-down period ทำงานถูกต้อง
- [ ] ใช้จ่ายเกิน limits ทำงานถูกต้อง
- [ ] Take a Break feature แสดงเมื่อจำเป็น
- [ ] ไม่มี variable reward / loot box
- [ ] ไม่มี FoMO mechanic
- [ ] Subscription cancel ง่าย ไม่ซ่อน
- [ ] แจ้งค่านายหน้า O2O อย่างโปร่งใส
- [ ] ไม่ขายเครื่องราง ของขลัง พิธีกรรม
- [ ] ราคาสมเหตุสมผลกับตลาดไทย
