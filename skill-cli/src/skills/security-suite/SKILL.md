# Security Suite

This skill combines multiple security disciplines into a single reference.

## 1. Security Review
- Use `/security-review` for automated code audits.
- Focus on OWASP Top 10 (SQLi, XSS, Auth failures, etc.).

## 2. Configuration Scanning
- Scan `.claude/` for misconfigurations.
- Protect `.env` files and sensitive credentials.

## 3. Vulnerability Hunting
- Hunt for exploitable vulnerabilities in remotely reachable services.
- Use `security-bounty-hunter` patterns for high-impact findings.
