- **maw wake กับ path ที่ไม่ใช่ ghq** — maw หา ai-server ไม่เจอเพราะมันอยู่นอก ghq root ควรมีวิธีระบุ path โดยตรง

## Honest Feedback

1. **Path management ยุ่งยาก** — ai-server อยู่ที่ `~/ai-server` ไม่ใช่ใน ghq root ทำให้ maw หาไม่เจอ ควรย้ายเข้า ghq หรือแก้ maw ให้รองรับ path นอก ghq
2. **Docker security hardening ไม่สม่ำเสมอ** — open-design มี read_only, no-new-privileges, mem_limit แต่ services อื่นไม่มี ควรเพิ่มให้ทุก container
3. **Deep learn ผลลัพธ์เยอะมาก** — 5 docs × ~500-1200 บรรทัด = เกือบ 4000 บรรทัด อาจจะย่อให้กระชับกว่านี้ได้

## Lessons Learned

- repo ที่มี Docker setup อยู่แล้ว (deploy/Dockerfile, docker-compose.yml) ไม่ต้องสร้างใหม่ — แค่ pull image + แก้ .env พอ
- Cloudflare tunnel แบบ token-based ควบคุม routes ผ่าน Dashboard ได้โดยไม่ต้อง restart container
- maw bud สร้าง repo ใหม่ตาม naming convention ของ Oracle แม้ว่าจะมี repo อยู่แล้ว — ต้องตัดสินใจว่าจะใช้ repo ไหน
