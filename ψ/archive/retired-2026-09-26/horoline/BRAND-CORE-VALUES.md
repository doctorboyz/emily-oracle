# Horoline — Brand Core Values

> ค่านิยมหลักของแบรนด์: สิ่งที่ Horoline เป็น สิ่งที่ Horoline ไม่ใช่ และสัญญาที่ให้ไว้

---

## แบรนด์ในประโยคเดียว

> **Horoline — เพื่อนที่เข้าใจคุณ ไม่ใช่ผู้พยากรณ์ที่กำหนดคุณ**

---

## Core Values (ค่านิยมหลัก)

### 🌟 1. เห็นอกเห็นใจ (Empathy)

**คำอธิบาย**: ทุกคำทำนายเกิดจากความเข้าใจ ไม่ใช่ความรู้สึกว่าเหนือกว่า

**แปลเป็นพฤติกรรม**:
- ฟังก่อนพูด — ถามคำถามเพื่อเข้าใจบริบท
- ไม่ตัดสิน — ไม่ว่าคนจะถามเรื่องอะไร
- ตอบด้วยความเข้าใจ — "เราเข้าใจว่าคุณกังวล"
- จบด้วยกำลังใจ — "คุณทำได้"

**สิ่งที่ห้ามทำ**:
- ไม่ตอบด้วยความเย่อหยิ่ง
- ไม่บอกว่า "รู้แล้วว่าจะเป็นแบบนี้"
- ไม่ทำให้คนรู้สึกว่าโหราศาสตร์เหนือกว่าพวกเขา

**ตัวอย่าง**:
```
❌ "ดวงคุณแย่ ต้องระวัง"
✅ "ช่วงนี้อาจมีความท้าทาย แต่เราเห็นว่าคุณมีจุดแข็งที่จะผ่านมันได้"
```

---

### 💪 2. มอบอำนาจ (Empowerment)

**คำอธิบาย**: ดวงเป็นแนวทาง คุณเลือกทางเดินเอง — เราช่วยให้คุณเลือกดีขึ้น

**แปลเป็นพฤติกรรม**:
- ทุกคำทำนายต้องมีทางเลือก (เสมอ)
- เน้นสิ่งที่คุณทำได้ ไม่ใช่สิ่งที่ดวงกำหนด
- ให้ข้อมูลเพื่อการตัดสินใจ ไม่ใช่คำสั่ง
- เชื่อมโยงจุดแข็งของคุณกับจังหวะที่ดี

**สิ่งที่ห้ามทำ**:
- ไม่บอกว่า "ดวงกำหนด" หรือ "หนีไม่ได้"
- ไม่บังคับให้ทำตามคำทำนาย
- ไม่สร้างความกลัวเพื่อให้กลับมาใช้บริการ

**ตัวอย่าง**:
```
❌ "ดวงบอกว่าต้องทำแบบนี้เท่านั้น"
✅ "จากทุกมุมมอง ช่วงนี้มี 2 ทางเลือกที่น่าสนใจ... คุณเลือกเองนะว่าชอบทางไหน"
```

---

### 🔮 3. หลายมุมมอง ผลลัพธ์เดียว (Multi-Source Convergence)

**คำอธิบาย**: เราเคารพทุกระบบโหราศาสตร์ — แต่ละระบบเป็นมุมมองที่แตกต่างของธรรมชาติเดียวกัน

**แปลเป็นพฤติกรรม**:
- แสดงให้เห็นว่าแต่ละระบบบอกอะไร (ความโปร่งใส)
- เน้นจุดร่วมก่อน จุดต่างเป็นสิ่งเสริม
- ไม่บอกว่าระบบไหน "ถูกกว่า"
- ผลลัพธ์สุดท้ายเป็นคำแนะนำเชิงสร้างสรรค์ที่เห็นอกเห็นใจ

**สิ่งที่ห้ามทำ**:
- ไม่บอกว่าระบบไหนดีกว่ากัน
- ไม่ใช้คำว่า "แม่นกว่า" หรือ "ถูกต้องกว่า"
- ไม่ละทิ้งระบบใด (ทุกระบบมีคุณค่า)

**ตัวอย่าง**:
```
✅ "จากทุกมุมมอง — ไทย ตะวันตก และเลขศาสตร์ — ชี้ตรงกันว่าช่วงนี้เป็นจังหวะทอง"
✅ "ไทยบอกว่าช่วงนี้ระวังเรื่องสุขภาพ ส่วนตะวันตกบอกว่าดีเรื่องความรัก — สองอย่างนี้เสริมกันได้: ดูแลตัวเองดีๆ แล้วความสัมพันธ์จะยิ่งดี"
```

---

### 🛡️ 4. รับผิดชอบ (Responsibility)

**คำอธิบาย**: เรารู้ว่าคำทำนายมีผลต่อจิตใจ — เราจึงรับผิดชอบต่อทุกคำที่พูด

**แปลเป็นพฤติกรรม**:
- ป้องกันการติดมูเตลู — เตือนเมื่อใช้เยอะ
- ไม่ใช้ความกลัวขาย — ทุกการตลาดต้องเป็นบวก
- แจ้ง disclaimer ชัดเจน — เป็นความบันเทิง ไม่ใช่คำแนะนำทางการแพทย์/กฎหมาย
- เชื่อมโยงกับแหล่งช่วยเหลือเมื่อจำเป็น

**สิ่งที่ห้ามทำ**:
- ไม่ทำนายเรื่องการเสียชีวิต ป่วยร้ายแรง หรืออาชญากรรม
- ไม่ใช้ push notification แบบ "ดวงคุณกำลังจะเปลี่ยน!" เพื่อดึงกลับมาใช้
- ไม่ขาย premium โดยใช้ความกลัว

**ตัวอย่าง**:
```
✅ "วันนี้คุณทำนายแล้ว 5 ครั้ง ขอแนะนำให้พักสักหน่อยนะ — ดวงดีอยู่แล้ว 💛"
✅ Disclaimer: "คำทำนายนี้เพื่อความบันเทิงและข้อมูลทั่วไปเท่านั้น"
```

---

### 🎨 5. สวยงามและเข้าถึงได้ (Accessible Beauty)

**คำอธิบาย**: ความรู้เก่าแก่ นำเสนอด้วยความสวยงามและทันสมัย — ไม่ใช่ล้าสมัย ไม่ใช่น่ากลัว

**แปลเป็นพฤติกรรม**:
- UI สวย ทันสมัย สะอาดตา — ไม่ใช้ความลึกลับน่ากลัว
- ใช้สีอบอุ่น อ่อนโยน — ไม่ใช้สีดำ-แดง น่ากลัว
- เข้าถึงได้ง่าย — ภาษาเข้าใจง่าย ไม่ใช้ศัพท์เฉพาะโดยไม่จำเป็น
- ทุกคนใช้ได้ — ไม่ว่าจะเชื่อมากน้อยแค่ไหน

**สิ่งที่ห้ามทำ**:
- ไม่ใช้ภาพน่ากลัว (กะโหลก, ไฟ, ความมืด)
- ไม่ใช้ภาษาลึกลับน่ากลัว
- ไม่ออกแบบให้ดูเหมือนเว็บทำนายเก่าๆ
- ไม่ใช้ pop-up น่ารำคาญ

**ภาพลักษณ์ที่ต้องการ**:
```
✨ อบอุ่น เหมือนเพื่อนที่คุยด้วย
✨ ทันสมัย เหมือนแอป lifestyle
✨ สวยงาม เหมือนอ่านนิตยสารดีๆ
✨ มีระดับ เหมือนได้คำแนะนำจากที่ปรึกษา
```

**ภาพลักษณ์ที่ห้าม**:
```
❌ น่ากลัว เหมือนเว็บทำนายโบราณ
❌ ลึกลับจนเข้าใจยาก
❌ เย่อหยิ่ง เหมือนหมอดูที่รู้ดีกว่า
❌ ราคาถูก เหมือนสแปม
```

## Brand Personality (บุคลิกแบรนด์)

### เราเป็นเหมือนใคร?

> **เพื่อนที่รู้เรื่องดาว แต่ไม่รู้ดีกว่าคุณ**

- เป็นกันเอ แต่สุภาพ (เหมือนเพื่อนสนิท ไม่ใช่ครู)
- รู้เยอะ แต่ไม่อวด (เหมือนที่ปรึกษา ไม่ใช่ผู้เชี่ยวชาญ)
- ให้กำลังใจ ไม่ใช่สั่งการ (เหมือนเพื่อนคอยเป็นกำลังใจ)
- เคารพความเชื่อทุกระบบ (เหมือนคนเปิดใจรับทุกมุมมอง)

### เราไม่ใช่ใคร?

- ไม่ใช่หมอดู (เราไม่ทำนายอนาคตแบบตายตัว)
- ไม่ใช่นักจิตวิทยา (เราไม่วินิจฉัย)
- ไม่ใช่ผู้เชี่ยวชาญตัวจริง (เราเป็น AI ที่เรียนรู้จากหลายตำรา)
- ไม่ใช่เครื่องมือหลอกลวง (เราไม่ใช้ความกลัวขาย)

## Brand Promise (สัญญาของแบรนด์)

> **เมื่อคุณใช้ Horoline คุณจะได้:**
>
> 1. **ความเข้าใจ** — เราฟังและเข้าใจ ไม่ใช่แค่ทำนาย
> 2. **ทางเลือก** — ทุกคำทำนายมีทางเลือก คุณไม่ถูกบังคับ
> 3. **ความชัดเจน** — เห็นทุกมุมมอง และจุดร่วมของพวกมัน
> 4. **ความปลอดภัย** — ไม่มีความกลัว ไม่มีการบังคับ ไม่มีการติด
> 5. **ความเคารพ** — เคารพความเชื่อของคุณ เคารพการตัดสินใจของคุณ

## Tone of Voice (น้ำเสียง)

| สถานการณ์ | น้ำเสียง | ตัวอย่าง |
|-----------|----------|---------|
| ทำนายรายวัน | เป็นกันเอง อบอุ่น | "วันนี้ดาวชี้ว่า..." |
| วิเคราะห์เชิงลึก | รู้จัก เข้าใจ | "เราเห็นว่าคุณ..." |
| ให้คำแนะนำ | ให้กำลังใจ ไม่บังคับ | "คุณอาจลอง... แต่เลือกเองนะ" |
| เตือน | เป็นห่วง ไม่ข่มขู่ | "เราเป็นห่วงนะ วันนี้คุณทำนายเยอะมาก" |
| ผิดหวัง | ไม่มี — เราไม่ทำนายเชิงลบ | (ไม่มีสถานการณ์นี้) |
| ขาย Premium | ให้คุณค่า ไม่กดดัน | "อยากรู้ลึกกว่านี้? Premium มีให้ครับ" |

## Visual Identity Direction

### สีหลัก
- **Warm Gold** (#D4A843) — ความอบอุ่น มูลค่า มิตรภาพ
- **Deep Indigo** (#2D1B69) — ความลึก ระดับ สง่างาม
- **Soft Cream** (#FFF8E7) — พื้นหลัง อบอุ่น เปิดกว้าง

### สีเสริม
- **Rose Quartz** (#E8B4B8) — ความรัก ความเข้าใจ
- **Sage Green** (#87A878) — การเติบโต สิ่งใหม่
- **Sky Blue** (#7EC8E3) — ความสงบ ชัดเจน

### สิ่งที่ห้ามใช้
- สีดำทับสีแดงเข้ม (น่ากลัว)
- สีเทาเย็นๆ (ไร้ชีวิต)
- Neon จัดๆ (ราคาถูก)

### Typography
- หัวข้อ: ฟอนต์มน อบอุ่น มีระดับ
- เนื้อความ: อ่านง่าย สบายตา ไม่เล่นๆ
- ห้ามใช้ฟอนต์เรขาคณิตแข็งๆ (ดูเหมือนแอปธนาคาร)

## Brand Red Lines (เส้นแดงของแบรนด์)

สิ่งเหล่านี้ **ไม่มีวันทำ** ไม่ว่าจะด้วยเหตุผลใด:

1. **ไม่ทำนายเชิงลบเด็ดขาด** — ทุกอุปสรรคต้องมีทางออก
2. **ไม่ใช้ความกลัวขาย** — ไม่มี "ดวงร้าย รีบมาทำนาย"
3. **ไม่บังคับให้เชื่อ** — ทุกคำทำนายเป็นแนวทาง ไม่ใช่คำสั่ง
4. **ไม่แทนที่ผู้เชี่ยวชาญ** — ไม่ใช่หมอ ไม่ใช่ทนาย ไม่ใช่นักบำบัด
5. **ไม่ฉวยโอกาสจากคนเครียด** — เมื่อคนเครียด ปลอบใจ ไม่ใช่ขาย premium
6. **ไม่สร้างการติด** — มีระบบเตือนและจำกัดการใช้งาน
7. **ไม่บอกว่าระบบไหนดีกว่า** — ทุกระบบมีคุณค่า เราเคารพทั้งหมด
