# CBT Reframing — แปลงคำทำนายเชิงลบเป็นเชิงบวก

## โครงสร้าง ABCDE

| ขั้น | ไทย | ตัวอย่างในบริบทมูเตลู |
|------|------|------------------------|
| A | เหตุการณ์ | ได้รับคำทำนายที่ท้าทาย |
| B | ความเชื่อ | "ดวงฉันแย่ ต้องเจอเรื่องร้าย" |
| C | ผลลัพธ์ | วิตกกังวล หวั่นไหว ตรวจดวงซ้ำๆ |
| D | โต้แย้ง | "คำทำนายเป็นไปได้อย่างหนึ่ง ไม่ใช่ความจริง ฉันเคยผ่านเรื่องยากมาแล้ว" |
| E | แนวทางใหม่ | "ท้าทายคือโอกาสเติบโต ฉันมีจุดแข็งที่จะผ่านมันได้" |

## ตารางแปลงภาษา (Language Transformation)

| ภาษาดั้งเดิม (ข่มขู่) | ภาษาปรับใหม่ (เสริมกำลัง) | Cognitive Distortion |
|------------------------|--------------------------|---------------------|
| "คุณจะเจอเรื่องร้าย" | "ช่วงนี้มีโอกาสเติบโตผ่านความท้าทาย — คุณมีจุดแข็งที่จะผ่านมันได้" | Catastrophizing |
| "ดวงคุณแย่เดือนนี้" | "เดือนนี้เหมาะกับการเตรียมตัวและวางแผน — ลงทุนตอนนี้ เก็บเกี่ยวทีหลัง" | Fortune telling |
| "ความสัมพันธ์จะจบ" | "ช่วงนี้เหมาะกับการทบทวนว่าคุณต้องการอะไรจากความสัมพันธ์ — คุณเลือกได้" | All-or-nothing |
| "ดวงร้ายล้อมรอบ" | "พลังงานช่วงนี้เชิญให้ดูแลตัวเอง — อะไรที่ทำให้คุณรู้สึกดีขึ้น?" | Overgeneralization |
| "คุณจะถูกทรยศ" | "ช่วงนี้ควรใส่ใจเรื่องความไว้วางใจ — เลือกให้ความไว้วางใจอย่างมีสติ" | Mind reading |
| "อุปสรรคขวางทาง" | "อุปสรรคเผยให้เห็นว่าอะไรสำคัญจริงๆ — ความท้าทายนี้สอนอะไรคุณ?" | Labeling |
| "ดาวไม่เข้าข้าง" | "ช่วงนี้เหมาะกับการเลือกอย่างมีสติ — ก้าวเล็กๆ วันนี้คืออะไร?" | External locus |
| "คุณควบคุมอะไรไม่ได้" | "บางสิ่งนอกควบคุม แต่การตอบสนองของคุณเป็นของคุณเสมอ" | Learned helplessness |

## กฎ 3 คำทำนาย (Three-Interpretation Rule)

เมื่อการ์ด/ดวงมีความหมายที่ท้าทาย → ต้องสร้างอย่างน้อย 3 การตีความ:
1. **การตีความที่ 1**: มุมมองท้าทาย (Challenge)
2. **การตีความที่ 2**: มุมมองเติบโต (Growth)
3. **การตีความที่ 3**: แนวทางปฏิบัติ (Action)

**ตัวอย่าง**: ดาวเสาร์เสวย (Saturn return)
1. Challenge: "ช่วงนี้มีความท้าทายในด้าน..."
2. Growth: "แต่เสาร์สอนให้อดทน มีวินัย — ทักษะที่จะเป็นประโยชน์ในอนาคต"
3. Action: "ลองตั้งเป้าหมายเล็กๆ ที่ทำได้จริง — ความสำเร็จเล็กๆ สะสมเป็นใหญ่"

## หลักการสำคัญ

- **ห้าม**: "แค่คิดบวก" — Toxic positivity เป็นอันตรายเช่นกัน
- **ห้าม**: ลดทอนความเจ็บปวดจริง — "ไม่เป็นไรหรอก" ไม่ใช่ reframing
- **ต้อง**: Reframing ต้องน่าเชื่อ — "ฉันสามารถเรียนรู้จากเรื่องนี้ได้" ดีกว่า "ฉันเก่งที่สุด"
- **ต้อง**: ทุกคำทำนายที่ท้าทายต้องผ่าน ABCDE pipeline ก่อนแสดงผล
