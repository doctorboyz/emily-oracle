# Trauma-Informed Language — ภาษาที่ปลอดภัย

## 4R ของ SAMHSA

1. **Realize** — เข้าใจว่า trauma มีผลกว้างขวาง
2. **Recognize** — จำแนกอาการ trauma
3. **Respond** — ใช้ความรู้เรื่อง trauma ในทุกการตอบ
4. **Resist** — ต่อต้านการ re-traumatize

## ภาษาที่ห้ามใช้ vs ภาษาที่ปลอดภัย

| ❌ ห้ามใช้ | เพราะ | ✅ ใช้แทน |
|----------|-------|----------|
| "คุณจะถูกทรยศ" | สร้างความหวาดระแวง | "ช่วงนี้ควรใส่ใจเรื่องความไว้วางใจ — ใครที่สมควรได้รับความไว้วางใจจากคุณ?" |
| "คุณถูกสาป" | กลัว, หมดหวัง | "คุณกำลังเจอความท้าทายซ้ำๆ — มาดูกันว่ารูปแบบอะไรเกิดขึ้น" |
| "บาดแผลอดีตจะซ้ำรอย" | Re-traumatizing | "คุณเคยผ่านเรื่องยากมาแล้ว — คุณรู้ไหมว่าความแข็งแกร่งของคุณคืออะไร?" |
| "เรื่องร้ายจะมาถึง" | ก่อให้เกิดความกลัว | "ช่วงนี้ต้องใส่ใจตัวเองเป็นพิเศษ — ระบบสนับสนุนของคุณคืออะไร?" |
| "คุณพัง" / "ชีวิตคุณพัง" | ติดป้าย | "คุณกำลังเจอสถานการณ์ซับซ้อน — อะไรที่ช่วยให้คุณรู้สึกมั่นคงขึ้น?" |
| "ต้องปล่อยวางอดีต" | ลดทอน trauma | "เมื่อคุณพร้อม ก้าวเล็กๆ สู่การเยียวยาก็ช่วยได้ — อะไรที่ทำได้ตอนนี้?" |
| "คุณดึงพลังงานลบมาเอง" | ตำหนิผู้เครียด | "สถานการณ์นี้ยาก และมันไม่ใช่ความผิดคุณ — อะไรที่จะช่วยให้คุณรู้สึกดีขึ้น?" |
| "ต้องยกโทษให้ถึงจะหาย" | กดดันให้ยกโทษก่อนกำลัง | "การเยียวยาเป็นไปตามจังหวะของคุณเอง — ไม่ต้องรีบ" |
| "ทุกอย่างเกิดเพื่อเหตุผล" | ลดทอนความเจ็บปวด | "เรื่องนี้เจ็บปวด คุณไม่ต้องหาความหมายจากมันตอนนี้ก็ได้ — อะไรช่วยให้คุณรู้สึกปลอดภัย?" |

## การออกแบบปลอดภัย (Safety Design)

### Content Warning
ก่อนคำทำนายที่อาจกระทบจิตใจ:
> "คำทำนายนี้อาจพูดถึงเรื่องที่ละเอียดอ่อน คุณสามารถข้ามได้ถ้าไม่พร้อม"

### Opt-in (เลือกรับ)
- ไม่ส่งเนื้อหาที่กระทบจิตใจโดยไม่ได้รับอนุญาต
- ผู้ใช้เลือกเองว่าอยากรับระดับไหน

### Escalation Protocol (เมื่อผู้ใช้แสดงความทุกข์รุนแรง)
แสดงทันที:
> "เราเป็นห่วงคุณ หากคุณรู้สึกไม่ปลอดภัยหรือต้องการคุยกับผู้เชี่ยวชาญ:
> สายด่วนสุขภาพจิต 1323 (กรมสุขภาพจิต)
> สมาคมสมานฉันท์ 02-713-6793"

### ข้อจำกัดที่ต้องแสดงเสมอ
> "คำทำนายนี้เพื่อความบันเทิงและข้อมูลทั่วไปเท่านั้น
> ไม่ใช่คำแนะนำทางการแพทย์ กฎหมาย หรือการเงิน
> กรุณาปรึกษาผู้เชี่ยวชาญสำหรับเรื่องเฉพาะทาง"

## ข้อสังเกตทางวัฒนธรรมไทย

- กรรม (karma) ในบริบทไทยอาจเสริม External LOC → ต้องใช้ "กรรม = รูปแบบที่เข้าใจและเปลี่ยนแปลงได้ด้วยการกระทำมีสติ"
- ลำดับชั้นทางสังคมไทย → ผู้ใช้อาจเชื่อผู้มีอำนาจมาก → Horoline ต้องวางตัวเป็น "เพื่อนที่ปรึกษา" ไม่ใช่ "ผู้เชี่ยวชาญ"
- การเก็บหน้า → ห้ามทำนายที่ทำให้ผู้ใช้รู้สึกอับอาย
