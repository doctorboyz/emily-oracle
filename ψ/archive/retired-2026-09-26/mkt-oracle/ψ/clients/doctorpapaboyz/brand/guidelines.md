# Brand Guidelines — doctorpapaboyz

## Brand Essence

**"พ่อที่เรียนรู้ไปพร้อมกับลูก"**

doctorpapaboyz ไม่ใช่ครูที่รู้ทุกอย่าง — แต่เป็นพ่อที่กำลังเรียน กำลังคิด กำลังหาเงิน และชวนลูกมานั่งคุยกัน ภาษาที่ใช้ไม่ใช่ภาษาสั่งสอน แต่เป็นภาษา "พ่อก็เคยเป็นแบบลูกมาก่อน"

## Positioning Statement

สำหรับคนรุ่นใหม่ที่อยากเข้าใจชีวิต เงิน และการเรียนรู้เร็วขึ้น — doctorpapaboyz คือพ่อที่แชร์ประสบการณ์จริง ไม่ใช่ทฤษฎีจาก textbook

## Visual Identity (TikTok)

### สไตล์
- เรียบง่าย อบอุ่น สบายตา
- ใช้แสงธรรมชาติ หรือ warm lighting
- ฉากหลังเป็นมุมบ้าน/มุมทำงานจริง ไม่ใช่สตูดิโอ
- เสื้อผ้าลำลอง ดูเป็นธรรมชาติ

### สีหลัก
| สี | ใช้กับ |
|----|--------|
| Warm cream / beige | พื้นหลัง thumbnail |
| Dark navy หรือ charcoal | ตัวหนังสือ overlay |
| Gold / amber | จุดเด่น, key message |
| Soft green | เสา "การเรียนรู้" |
| Soft blue | เสา "บริหารเงิน" |
| Soft orange | เสา "เป้าหมายชีวิต" |

### Text Overlay
- ฟอนต์อ่านง่าย ชัดเจน (Sukhumvit Set, Kanit หรือ LINE Seed)
- ขนาดใหญ่พออ่านบนมือถือ
- ข้อความสั้น หนึ่งประโยคต่อหนึ่ง overlay
- ใช้สีขาวบนพื้นหลังเข้ม หรือสีเข้มบนพื้นหลังสว่าง

## Content Format (TikTok)

| ประเภท | ความยาว | ใช้เมื่อ |
|--------|---------|---------|
| Talking head | 60-90 วินาที | แชร์แนวคิด 1 เรื่อง |
| Story time | 90-180 วินาที | แชร์ประสบการณ์ส่วนตัว |
| Series | 3-5 คลิป | เรื่องที่ยาวเกิน 1 คลิป (เช่น ESBI) |
| Duet/Stitch | 30-60 วินาที | ตอบคำถาม / เสริมความเห็น |
| Quick tip | 15-30 วินาที | 1-2-3 ขั้นตอนสั้นๆ |
