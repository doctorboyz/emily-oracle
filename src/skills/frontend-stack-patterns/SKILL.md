# Frontend Stack Patterns

This skill unifies all frontend-specific guidance into a single reference.

## 1. React & Next.js
- Use Server Components by default in Next.js 13+ (App Router).
- Keep state management minimal; use `useState`/`useContext` or Server Actions.
- Use `nextjs-turbopack` for fast development.

## 2. Design & Styling
- Follow the `design-system` standards.
- Use `frontend-design` principles for polished, responsive interfaces.
- Prefer Tailwind CSS or CSS Modules.

## 3. Presentations & Demos
- Use `frontend-slides` for HTML-based presentations.
- Use `ui-demo` (Playwright) to record application walkthroughs.
