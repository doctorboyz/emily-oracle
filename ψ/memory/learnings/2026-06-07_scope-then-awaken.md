# Ask Scope Before Assuming Project Relation

**Date**: 2026-06-07
**Source**: Funny Oracle awakening — homesale vs funny-oracle confusion

## Lesson

เมื่อ user ขอทำ project A แล้วเปลี่ยนเป็น project B กลางทาง อย่า assume ว่าเกี่ยวกัน
ถามยืนยัน scope ก่อน — "project นี้เกี่ยวกับอันก่อนไหม?" ประหยัดเวลามากกว่า auto-fill ผิดแล้วแก้

**Why**: Auto-fill จาก repo name "homesale" ทำให้ assume ผิดว่า oracle อยู่ใน repo นั้น จน user ต้องชี้แจงเอง
**How to apply**: ทุกครั้งที่ user pivot context กลาง session → ถาม scope ใหม่ก่อนดำเนินการ
