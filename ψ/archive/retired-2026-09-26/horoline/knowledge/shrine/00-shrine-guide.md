# Shrine Guide — แนวทางการแนะนำสถานที่ศักดิ์สิทธิ์

## หลักการสำคัญ

1. **เสริมพลังงานบวก ไม่ใช่แก้ดวง**: "เป็นอีกทางเลือกที่เสริมพลังงานบวก" ไม่ใช่ "ดวงคุณแย่ ต้องไปไหว้"
2. **เคารพทุกศาสนา**: วัด ศาลเจ้า โบสถ์ มัสยิด ทุกแห่งเคารพเท่ากัน
3. **แนะนำ ไม่บังคับ**: "ลองไปไหว้ดูสิคะ" ไม่ใช่ "ต้องไปไหว้"
4. **ไม่ขายสิ่งของ**: ไม่แนะนำให้ซื้อของจากศาลเพื่อการค้า
5. **ให้ข้อมูลเป็นประโยชน์**: เวลา เส้นทาง วิธีไหว้ ควรระวัง

## การจับคู่ศาลกับผู้ใช้

### การจับคู่ตามราศี

| ราศี | ธาตุ | ศาลที่เหมาะ (ประเภท) | เทพที่เกี่ยวข้อง |
|-------|------|---------------------|------------------|
| เมษ | ไฟ | ศาลเทพเกี่ยวกับการเริ่มต้น ความกล้า | พระอิศวร, พระพรหม |
| พฤษภ | ดิน | ศาลเทพเกี่ยวกับความมั่นคง ความอุดม | พระแม่ธรณี, พระพุทธรูปประจำราศี |
| เมถุน | ลม | ศาลเทพเกี่ยวกับการสื่อสาร ความคิด | พระพิฆเนศ, ท้าวเวสสวัณ |
| กรกฎ | น้ำ | ศาลเทพเกี่ยวกับครอบครัว ความรัก | พระแม่กวนอิม, พระพุทธชินราช |
| สิงห์ | ไฟ | ศาลเทพเกี่ยวกับอำนาจ ผู้นำ | พระอิศวร, พระพุทธรูปประจำราศี |
| กันย์ | ดิน | ศาลเทพเกี่ยวกับสุขภาพ การรับใช้ | พระแม่ธรณี, พระปิดตา |
| ตุลย์ | ลม | ศาลเทพเกี่ยวกับความสมดุล ความสัมพันธ์ | พระพิฆเนศ, ศาลท้าวมหาพรหม |
| พิจิก | น้ำ | ศาลเทพเกี่ยวกับการเปลี่ยนแปลง ความลึกลับ | พระแม่กวนอิม, พระนาคประดับ |
| ธนู | ไฟ | ศาลเทพเกี่ยวกับการเดินทาง ปรัชญา | พระพุทธชินราช, ศาลเจ้าแม่ทับทิม |
| มังกร | ดิน | ศาลเทพเกี่ยวกับการงาน ความมุ่งมั่น | พระแม่กวนอิม, พระปิดตา |
| กุมภ์ | ลม | ศาลเทพเกี่ยวกับนวัตกรรม มนุษยธรรม | พระพิฆเนศ, ศาลเจ้าเจ็ด |
| มีน | น้ำ | ศาลเทพเกี่ยวกับจิตวิญญาณ การปล่อยวาง | พระพุทธรูปประจำราศี, วัดริมน้ำ |

### การจับคู่ตามเสวยอายุ

| ดาวเสวย | แนะนำประเภทศาล | เทพประจำดาว |
|----------|----------------|---------------|
| อาทิตย์ | ศาลเกี่ยวกับอำนาจ ผู้นำ ความสำเร็จ | พระอาทิตย์, พระศิวะ |
| จันทร์ | ศาลเกี่ยวกับจิตใจ ความอบอุ่น แม่ | พระจันทร์, พระแม่กวนอิม |
| อังคาร | ศาลเกี่ยวกับความกล้า พลังงาน | พระอังคาร, ศาลเจ้าแม่ทับทิม |
| พุธ | ศาลเกี่ยวกับภูมิปัญญา การค้า | พระพิฆเนศ, ท้าวเวสสวัณ |
| พฤหัสบดี | ศาลเกี่ยวกับธรรมะ การเรียน | พระครู, วัดเก่าแก่ |
| ศุกร์ | ศาลเกี่ยวกับความรัก ความงาม | พระแม่กวนอิม, ศาลเจ้าแม่ทับทิม |
| เสาร์ | ศาลเกี่ยวกับวินัย ความอดทน | พระเสาร์, วัดป่า |
| ราหู | ศาลเกี่ยวกับจิตวิญญาณ การเปลี่ยนแปลง | ศาลราหู, วัดใต้ |
| เกตุ | ศาลเกี่ยวกับการปล่อยวาง จิตวิญญาณ | วัดป่า, สถานที่สงบ |

### การจับคู่ตามวัตถุประสงค์

| วัตถุประสงค์ | คำแนะนำ | ศาลตัวอย่าง (กรุงเทพฯ) |
|-------------|---------|----------------------|
| การงาน | "เสริมพลังงานด้านการงาน" | ศาลท้าวมหาพรหม, วัดพระแก้ว |
| ความรัก | "เสริมพลังงานด้านความสัมพันธ์" | ศาลเจ้าแม่ทับทิม, ศาลพระพิฆเนศ |
| การเงิน | "เสริมพลังงานด้านโชคลาภ" | ศาลท้าวเวสสวัณ, วัดพระแก้ว |
| สุขภาพ | "เสริมพลังงานด้านสุขภาพ" | วัดพระศรี, วัดป่า |
| จิตวิญญาณ | "เสริมพลังงานด้านจิตใจ" | วัดป่า, วัดริมน้ำ |

## รูปแบบการแนะนำ

### รูปแบบที่ถูกต้อง

```
จากดวงของคุณ ช่วงนี้เหมาะกับการไหว้ขอพรเพื่อเสริมพลังงานบวก:
🏛️ {ชื่อศาล} — {เหตุผลจากราศี/ช่วงเวลา}
📍 {จังหวัด/เขต} — {ระยะทางถ้ามี}
🙏 {ของที่นำไป} — {คำแนะนำเบาๆ}

เคล็ดเสริม: {สีประจำวัน/เลขมงคล}
```

### สิ่งที่ห้ามทำ

| ห้าม | ทำแทน |
|------|--------|
| "ดวงคุณแย่ ต้องไปไหว้" | "ช่วงนี้เหมาะกับการเสริมพลังงานบวก" |
| "ต้องไปศาลนี้เท่านั้น" | "มีหลายที่ที่เหมาะ อยากแนะนำที่นี้" |
| "ถ้าไม่ไปไหว้จะเป็นอะไร" | "เป็นอีกทางเลือกที่เสริมพลังงานบวก" |
| ขายของ/บริการจากศาล | "ถ้าอยากร่วมทำบุญ สามารถทำได้ตามสะดวก" |

## โครงสร้างไฟล์ศาล (shrine file format)

แต่ละศาลมีไฟล์ `.md` เฉพาะ ที่ `knowledge/shrine/region/<region>/<shrine-name>.md`

โครงสร้าง:
1. รายละเอียด (detail): ชื่อเต็ม, ประวัติ, ความสำคัญ
2. สถานที่ (location): ที่อยู่, พิกัด GPS, แผนที่, เวลาเปิด-ปิด
3. การเดินทาง (transport): BTS/MRT, รถประจำทาง, รถยนต์, ที่จอดรถ
4. การไหว้ (worship): ของที่นำไป, คำอธิษฐาน, วิธีไหว้, ข้อควรระวัง
5. เคล็ดลับ (tips): เวลาที่คนน้อย, ฤกษ์ดี, ของหมุนเวียน
6. เรื่องราว (stories): ตำนาน, ประวัติ, ความเชื่อ, ปาฏิหาริย์
7. ข้อมูลเพิ่มเติม (extras): เทศกาล, งานประจำปี, ข้อควรทราบ
