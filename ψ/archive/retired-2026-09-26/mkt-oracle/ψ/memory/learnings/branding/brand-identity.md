# Brand Identity

## Brand Blueprint

1. **Brand Essence** — คำเดียวที่อธิบายแบรนด์
2. **Brand Promise** — สัญญากับลูกค้า
3. **Brand Personality** — ถ้าแบรนด์เป็นคน เป็นคนแบบไหน?
4. **Voice & Tone** — พูดอย่างไร? เป็นกันเอง? มืออาชีพ? สนุก?
5. **Visual Identity** — สี, ฟอนต์, โลโก้, icon style

## Brand Voice Spectrum

```
Informal ←────────────────────→ Formal
  Fun    ←────────────────────→ Serious
  Bold   ←────────────────────→ Safe
  Loud   ←────────────────────→ Quiet
```

เลือกจุดบน spectrum แล้ว stick with it ทุก channel
