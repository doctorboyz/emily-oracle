# Mobile Stack Patterns

This skill unifies all mobile-specific guidance into a single reference.

## 1. Flutter & Dart
- Use `dart-flutter-patterns` for robust, cross-platform apps.
- Follow `flutter-dart-code-review` standards.

## 2. iOS (SwiftUI)
- Use `swiftui-patterns` for modern declarative UI.
- Follow Swift Concurrency patterns (`swift-concurrency-6-2`).
- Use `swift-actor-persistence` for safe data handling.

## 3. Cross-Platform (KMP)
- Use `android-clean-architecture` and `compose-multiplatform-patterns` for Kotlin Multiplatform projects.
