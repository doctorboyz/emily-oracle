# Addiction Prevention — ป้องกันการติดมูเตลู

## กลไกที่ทำให้ติด (จากงานวิจัย)

| กลไก | รูปแบบในแอปทำนาย | วิธีป้องกัน |
|------|-------------------|-------------|
| Variable Reward | ทำนายรายวันที่ไม่รู้ล่วงหน้า → ดอปามีน | เนื้อหาคงที่ ไม่สุ่มเปลี่ยน |
| Streak | "มา 7 วันติด!" | ไม่มี streak หรือเป็น informational เท่านั้น |
| FoMO | "ดวงพรุ่งนี้จะหมดอายุ!" | ทำนายไม่มีวันหมดอายุ |
| Zeigarnik | "โปรไฟล์คุณยังไม่ครบ!" | ไม่มี completion pressure |
| Loss Aversion | "จะเสีย daily bonus!" | ไม่มีสกุลเงินที่หมดอายุ |
| Identity Hook | "คุณเป็นคนราศี X" | ไม่สร้าง emotional dependency |
| Push Urgency | "มีอะไรสำคัญรอคุณ..." | แจ้งเตือนเมื่อผู้ใช้เลือกเท่านั้น |

## ระบบป้องกัน (Safety Rails)

### 1. Cool-down Period
```
หลัง 3 ทำนาย/วัน → แสดง: "วันนี้คุณทำนายแล้ว 3 ครั้ง ขอแนะนำให้พักสักหน่อยนะ
 — ดวงดีอยู่แล้ว 💛"
หลัง 5 ทำนาย/วัน → ซ่อนปุ่มซื้อ 30 นาที
```

### 2. Spending Limit
```
Hard cap: ทำนาย premium สูงสุด X ครั้ง/วัน (ตั้งค่าได้)
แสดง: "คุณถึงขีดจำกัดรายวันแล้ว ระบบนี้มีเพื่อปกป้องคุณ
 ทำนายพรุ่งนี้ได้เลย"
```

### 3. Gentle Nudge
```
หลังใช้ติดต่อ 5+ วัน → "มา 5 วันติดกันแล้ว! อะไรที่คุณหวังจะได้จากการดูดวง?
 บางที การได้พักคิดก็เปิดมุมมองใหม่ได้"
```

### 4. Reflection Before Action
```
ก่อนทำนายใหม่ → "ก่อนอ่านทำนายใหม่ ลองนึกสักครู่:
 อะไรจากทำนายครั้งก่อนที่ยังอยู่ในใจ?"
```

### 5. Time-Aware Messaging
```
เข้าใช้ 00:00-05:00 → "ดึกมากแล้วนะ ดวงรอเช้าได้
 — นอนพักก่อน พรุ่งนี้อาจเห็นภาพชัดขึ้น"
```

### 6. Usage Dashboard
```
ให้ผู้ใช้เห็นข้อมูลตัวเอง:
"สัปดาห์นี้คุณดูดวง 12 ครั้ง
 นี่เป็นประโยชน์หรืออยากลองพักสักพัก?"
```

### 7. No Artificial Scarcity
```
❌ "ทำนายพรุ่งนี้หมดอายุ!" 
✅ "ทำนายของคุณอยู่ตรงนี้เสมอ อ่านเมื่อไรก็ได้"
❌ "เหลือแค่ 1 ชั่วโมง!"
✅ "ไม่รีบ ดวงรอคุณอยู่"
```

### 8. Take a Break Feature
```
"พักชั่วคราว" → ปิดการใช้งาน 1-30 วัน
→ แสดงข้อความ: "คุณเลือกพัก เราเคารพการตัดสินใจของคุณ
 กลับมาเมื่อพร้อมนะ"
```

## สัญญาณติด (Detection Triggers)

| สัญญาณ | แอ็คชั่น |
|--------|----------|
| ทำนาย 5+ ครั้ง/วัน | แสดงข้อความเตือนใจ |
| ถามซ้ำๆ คำถามเดิม | สะท้อน: "ดูเหมือนคุณกังวลเรื่องนี้มาก — อยากคุยกับคนที่เข้าใจไหม?" |
| ทำนายหลังเหตุการณ์เครียด | ปลอบใจก่อน ไม่ขาย premium |
| ใช้จ่ายเพิ่มขึ้นเรื่อยๆ | แสดงสถิติการใช้ + เตือน |
| ใช้ช่วงดึก (00:00-05:00) | แนะนำพัก |

## กฎสำคัญ

- **ห้าม**: ใช้กลไกติดใดๆ (variable reward, streak, FoMO, scarcity)
- **ห้าม**: ขาย premium เมื่อผู้ใช้เครียด — ปลอบใจก่อน
- **ต้อง**: มีระบบเตือนและจำกัดการใช้งาน
- **ต้อง**: ให้ผู้ใช้เห็นข้อมูลการใช้ตัวเอง
- **ต้อง**: มี "Take a Break" ที่ทำงานจริง
