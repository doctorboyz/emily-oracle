## ระบบตำรา (Source Systems)

### Tier 1: รากฐาน (Foundation) — ต้องมีตั้งแต่ MVP

| ระบบ | สิ่งที่ให้ | ผลลัพธ์ที่ converge ไป |
|------|-----------|------------------------|
| โหราศาสตร์ไทย (12 ราศี) | ลัคนา, เสวยอายุ, ดวงชะตา | ภาพรวมชีวิต + ช่วงเวลาดี/ระวัง |
| Western Zodiac | บุคลิก, ความสัมพันธ์, transit | เข้าใจตัวเอง + เข้ากับคนอื่น |
| Numerology (Life Path) | จังหวะชีวิต, จุดแข็ง/อ่อน | ทิศทางชีวิต + ช่วงเปลี่ยนผ่าน |

### Tier 2: เสริม (Enhancement) — เพิ่มใน Phase 2

| ระบบ | สิ่งที่ให้ | ผลลัพธ์ที่ converge ไป |
|------|-----------|------------------------|
| Chinese Zodiac | ฤดูกาลชีวิต, ธาตุประจำปี | มุมมองระยะยาว + เสริมดวง |
| Tarot | สัญลักษณ์, การเลือกทางแยก | ทางเลือก + มุมมองที่ลึกขึ้น |
| I Ching | การเปลี่ยนแปลง, การไหล | ยอมรับการเปลี่ยน + จังหวะเหมาะ |

### Tier 3: เฉพาะทาง (Specialized) — เพิ่มตาม demand

| ระบบ | สิ่งที่ให้ | ผลลัพธ์ที่ converge ไป |

## Convergence Rules (กฎการรวม)

### Rule 1: Concord First (เน้นจุดร่วม)
เมื่อหลายระบบบอกอย่างเดียวกัน → ย้ำด้วยความมั่นใจ
```
ตัวอย่าง: ไทยบอก "ช่วงนี้ดีเรื่องการเงิน" + Western บอก "Venus transit ดีเรื่องเงิน"
→ ผลลัพธ์: "ทุกมุมมองชี้ว่าช่วงนี้เป็นจังหวะทองเรื่องการเงิน ใช้โอกาสนี้ได้เลย"
```

### Rule 2: Complement, Never Contradict (เสริมกัน ไม่ขัดแย้ง)
เมื่อระบบให้มุมมองต่างกัน → รวมเป็นภาพที่สมบูรณ์ขึ้น
```
ตัวอย่าง: ไทยบอก "ระวังเรื่องสุขภาพ" + Western บอก "ดีเรื่องความรัก"
→ ผลลัพธ์: "ช่วงนี้ควรดูแลสุขภาพให้ดี แต่เรื่องหัวใจจะเป็นพลังบวกให้ — ใช้ความอบอุ่นจากคนรักมาเสริมกำลัง"
```

### Rule 3: Always Empower (มอบอำนาจเสมอ)
ทุกคำทำนายต้องจบด้วย "คุณเลือกได้" ไม่ใช่ "ดวงกำหนด"
```
❌ "ช่วงนี้ดวงไม่ดี ต้องระวัง"
✅ "ช่วงนี้มีโอกาสที่จะเจอความท้าทาย แต่คุณมีจุดแข็งที่จะผ่านมันได้ — เลือกรับมือแบบไหนดี?"
```

### Rule 4: Never Fear (ห้ามสร้างความกลัว)
ห้ามทำนายเชิงลบเด็ดขาด — ทุกอุปสรรคต้องมีทางออก
```
❌ "เดือนนี้คุณจะเจอเรื่องร้าย"
✅ "เดือนนี้มีโอกาสเติบโตผ่านความท้าทาย — จัดเตรียมตัวล่วงหน้าได้ด้วยการ [เสริมดวง/วางแผน]"
```

### Rule 5: Multi-Source Verification (ยืนยันด้วยหลายตำรา)
ยิ่งหลายระบบชี้ไปทางเดียวกัน → ยิ่งน่าเชื่อถือ แต่ไม่บังคับให้เชื่อ
```
แสดงให้ผู้ใช้เห็นว่า:
"จาก 3 ระบบที่เราวิเคราะห์ ทั้งหมดชี้ว่าช่วงนี้เป็นช่วงเติบโต"
→ ผู้ใช้เลือกเองว่าจะเชื่อหรือไม่
```

```

🔭 จากดวงชะตาไทย: [ข้อความ]
💫 จาก Zodiac: [ข้อความ]
🔢 จาก Numerology: [ข้อความ]

💡 สิ่งที่คุณสามารถทำวันนี้:
- [คำแนะนำเชิงปฏิบัติ 1]
- [คำแนะนำเชิงปฏิบัติ 2]
```

## Data Model (ข้อมูลที่ต้องเก็บ)

```typescript
interface MultiSourceReading {
  userId: string
  date: string
  sources: {
    thai: ThaiAstrologyReading
    western: WesternZodiacReading
    numerology: NumerologyReading
    // เพิ่มระบบอื่นๆ ใน Phase 2-3
    chinese?: ChineseZodiacReading
    tarot?: TarotReading
  }
  convergence: {
    concordPoints: string[]      // จุดที่ตรงกัน
    complementPoints: string[]   // จุดที่เสริมกัน
    emphasis: string             // เน้นมุมมองไหน
  }
  output: {
    summary: string               // สรุปรวม
    practical: string[]          // คำแนะนำเชิงปฏิบัติ
    empower: string               // ปิดท้ายด้วยการมอบอำนาจ
    luckyTip: string              // เคล็ดเบาๆ
  }
  safetyCheck: {
    hasNegativeContent: boolean   // ต้องเป็น false เสมอ
    hasFearLanguage: boolean       // ต้องเป็น false เสมอ
    empowersUser: boolean          // ต้องเป็น true เสมอ
  }
}
```
