# S45 Hospital — Client Overview

## Brand Summary

S45 Clinic คือสถาบันศัลยกรรมความงาม ก่อตั้งโดย **นพ.กิตติศักดิ์ วงค์เทียนชัย (หมอตี้)** ตั้งแต่ปี 2013 เริ่มจากภูเก็ต (Siam International Clinic) → 2016 สุขุมวิท 45 → 2021 flagship สุขุมวิท 33 และกำลังสร้าง **S45 Hospital** โรงพยาบาลศัลยกรรมครบวงจร ที่รัชดา-เทียมร่วมมิตร เปิดกลางปี 2026

**Growth**: ปี 2022 เติบโต 50% / ผู้ป่วย 85% ไทย 15% ต่างชาติ (อินโดนีเซีย กัมพูชา ลาว จีน ยุโรป ออสเตรเลีย อเมริกา)
**Signature Service**: เสริมจมูกเทคนิค Open Rhinoplasty ด้วยกระดูกซี่โครง (RIB Rhinoplasty) + แก้จมูกเคสยาก
**USP**: "มากกว่าความสวยคือการรักษา" — เชี่ยวชาญเคสถูกปฏิเสธจากที่อื่น
**Investment**: MASTER Group (Master Style PCL) ถือหุ้น 40%
