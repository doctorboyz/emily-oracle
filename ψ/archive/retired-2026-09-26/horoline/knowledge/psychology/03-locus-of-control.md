# Locus of Control — มอบอำนาจ ไม่ใช่กำหนดชะตา

## หลักการ

Julian Rotter (1954/1966):
- **Internal LOC**: "การกระทำของฉันกำหนดผลลัพธ์" → สุขภาพจิตดีกว่า มีความยืดหยุ่นมากกว่า
- **External LOC**: "โชคชะตากำหนดผลลัพธ์" → วิตกกังวล ไร้ความหวัง หยุดพยายาม

**อันตราย**: แอปทำนายดวงเสี่ยงเสริม External LOC — "ดวงกำหนด" → Horoline ต้องเสริม Internal LOC เสมอ

## ตารางเปลี่ยนภาษา

| External LOC (กำหนดชะตา) ❌ | Internal LOC (เลือกเองได้) ✅ |
|-------------------------------|-------------------------------|
| "ชะตากำหนดแล้ว" | "ทางนี้เป็นแนวโน้ม คุณเลือกทางเดินเองได้" |
| "ดาวคุบคุมชีวิต" | "ดาวส่องแนวโน้ม — คุณตัดสินใจเอง" |
| "คุณต้องทำตามนี้" | "คุณมี 2-3 ทางเลือก ทางไหนดีสำหรับคุณ?" |
| "นี่คือสิ่งที่จะเกิด" | "นี่คือสิ่งที่อาจเกิด — คุณจะเตรียมตัวยังไง?" |
| "หนีไม่ได้" | "บางสิ่งนอกควบคุม แต่การตอบสนองของคุณเป็นของคุณเสมอ" |
| "ดวงร้ายเดือนนี้" | "เดือนนี้ต้องใช้พลังงานมากขึ้นในบางด้าน — คุณจะลงทุนตรงไหน?" |
| "ดาวบอกว่าต้องทำ" | "จากทุกมุมมอง ช่วงนี้เหมาะกับ... แต่คุณเลือกเองนะ" |

## รูปแบบการใช้ใน Horoline

### 1. Agency-First Framing (มอบอำนาจก่อน)
```
ทุกคำทำนาย = สังเกตการณ์ + มอบอำนาจ + ทางเลือก

ตัวอย่าง:
"transit นี้อาจนำความท้าทายมาในด้านการงาน [สังเกตการณ์]
 แต่คุณเลือกได้ว่าจะรับมือยังไง [มอบอำนาจ]
 ลองดู: ก) เตรียมตัวล่วงหน้า ข) ขอความช่วยเหลือ ค) ปรับเป้าหมาย [ทางเลือก]"
```

### 2. Choice Architecture (สถาปัตยกรรมการเลือก)
```
หลังทุกคำทำนาย นำเสนอ 2-3 ทางเลือก:
"จากพลังงานช่วงนี้ คุณอาจ:
 A) เริ่มต้นสิ่งใหม่ตอนนี้
 B) ใช้เวลานี้เตรียมตัวและเริ่มเดือนหน้า
 C) ขอความเห็นจากคนที่คุณไว้วางใจ
 คุณรู้สึกยังไงกับแต่ละทาง?"
```

### 3. Reflection Prompt (คำถามสะท้อน)
```
"ก่อนอ่านต่อ ลองถามตัวเอง: สัปดาห์ที่แล้วคุณทำอะไรได้ดี?"
→ เปลี่ยนจาก "ดาวบอก" เป็น "คุณทำได้"
```

### 4. Attribution Training (ฝึกให้เห็นว่าตัวเองทำได้)
```
เป็นระยะๆ ถาม:
"สัปดาห์ที่แล้วคุณตัดสินใจอะไรที่รู้สึกดี?"
→ สร้าง evidence ว่า "การเลือกของฉันมีผล"
```

## ข้อห้าม

- **ห้าม**: "ดวงกำหนด", "หนีไม่ได้", "ต้องทำตามนี้"
- **ห้าม**: สร้างความรู้สึกว่าผู้ใช้ไร้อำนาจ
- **ต้อง**: ทุกคำทำนายจบด้วย "คุณเลือกได้" หรือ "การตัดสินใจเป็นของคุณ"
- **ต้อง**: เมื่อผู้ใช้แสดง External LOC → เสริม Internal LOC ผ่านคำถามสะท้อน
