# Social Media Platform Playbook

## Platform Characteristics

| Platform | ฟอร์แมตที่ทำงาน | กลุ่มเป้าหมาย | ความถี่โพสต์ | Algorithm |
|----------|------------------|---------------|--------------|-----------|
| X/Twitter | Short text, thread, GIF | ข่าว, tech, opinion | 3-5x/day | Real-time, recency |
| Instagram | Photo, Reel, Story, Carousel | Lifestyle, visual, gen Z | 1-2x/day feed, daily Story | Interest-based |
| TikTok | Short video (15s-3min) | Gen Z, entertainment | 1x/day | Discovery-first |
| Facebook | Text, photo, video, group | ครอบคลุม, อายุมากขึ้น | 1x/day | Social graph |
| LinkedIn | Article, post, document | B2B, มืออาชีพ | 3-5x/week | Engagement + network |
| YouTube | Long + Short video | ทุกกลุ่ม, search-driven | 1-2x/week | Search + recommendation |

## Autopost Workflow

1. สร้าง content ใน drafts/
2. Human review และ approve
3. ตั้งเวลาใน calendar/
4. Social Media Manager โพสต์ผ่าน platform MCP
5. ติดตาม engagement ใน analytics

## Content Adaptation per Platform

- **ไม่โพสต์เนื้อหาเดียวกันทุก platform โดยไม่ปรับ**
- ปรับความยาว, ภาษา, ฟอร์แมต ตาม platform
- รักษา core message เดียวกัน แต่เปลี่ยนรูปแบบ
