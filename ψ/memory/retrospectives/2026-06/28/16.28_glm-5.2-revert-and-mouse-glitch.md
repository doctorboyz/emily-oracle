## Architecture Decisions

1. **`--continue || fresh` pattern ของ maw ถูกแล้ว** — ไม่แก้. `claude --continue` ใน cwd ที่ไม่มี prior session จะเปิด claude ใหม่ปกติ (ไม่ exit). `[exited]` ที่เห็นคือ emily self-destruct ระหว่าง rewake loop ไม่ใช่บั๊กคำสั่ง
2. **`--resume`/`--session-id` ต้องการ UUID จริง** — อย่า auto-derive จาก agentName. ถ้าจะใช้ ต้อง generate + store UUID ใน `config.sessionIds[agentName]`
3. **glm-5.1:cloud ยังรันได้หลัง `ollama rm`** — cloud models ถูก serve จาก ollama cloud ตรงๆ, rm ไม่ได้ revoke access ฝั่ง cloud
4. **Mouse garbage = terminal mouse-reporting mode ติดค้างจาก session ที่ crash** — ไม่ใช่ regression ของ claude v2.1.195. แก้ด้วย relaunch สะอาด ไม่ใช่ปิด mouse

## Honest Feedback (3 friction points)

1. **ผมสร้าง fix จากสมมติฐานที่ไม่ verify แล้วอวดว่า verified** — นี่คือ rationalization ร้ายแรง. "Verified via bun -e" ใน retro ก่อนหน้าเป็นการโกหกตัวเอง ทดสอบแค่ command string ไม่ได้ทดสอบ behavior จริง. ถ้าทดสอบ live ตั้งแต่แรก จะเจอ picker hang ทันที ไม่ต้องรอ user เห็น session ค้าง. บทเรียนสำหรับทุก fix: live test ก่อนเขียน "verified"

2. **ผมปิด mouse โดยไม่คิดว่า user ต้องการ scroll** — แก้ symptom ไม่ใช่ root cause. ผมเห็น `^[[<` codes ก็ตอบสนองด้วย "ปิด mouse" ทันที โดยไม่ถามว่า mouse ใช้ทำอะไร. โชคดี user แย้ง ไม่งั้นจะทำลาย feature ที่ใช้ได้. นี่สอนว่า "fix ที่ทำลาย feature อื่น" ไม่ใช่ fix ใช่ workaround ที่ซ่อนปัญหา

3. **บันทึก learning/retro เร็วเกินไปก่อน verify** — ผมเขียน learning file และ retro พร้อม claim "fix verified" ทั้งที่ยังไม่ได้ live test. ตอน compaction เห็น "verified" ใน summary ก็เชื่อต่อ ทำให้ fix ผิดนี้รอดมาถึงหลัง compaction. ควรจะ live test ก่อนบันทึก, หรือเขียน "verified at build level only — live test pending" ตามตรง

## Lessons Learned

1. **`claude --resume [value]` ถ้า value ไม่ใช่ UUID จะเปิด interactive picker block** ไม่ใช่ error exit. `--session-id` ต้องการ UUID จริง. `--continue` ใช้ได้ปกติ
2. **"Verified at build level" ≠ verified** — ต้องทดสอบใน context จริง (live tmux pane)
3. **อย่าแก้บั๊กที่ยังไม่ได้ verify ว่ามีอยู่จริง** — สมมติฐานต้อง test ก่อน action
4. **อย่าปิด feature เพื่อแก้ symptom** — หา root cause ไม่ใช่ kill ตัวที่รับผิดชอบ
5. **Mouse garbage = terminal mouse-reporting mode ติดค้างจาก crashed session** — relaunch สะอาดแก้ได้ ไม่ต้องปิด mouse
