## Strategic Implications

### Tiered Pricing Pyramid

```
                    ┌─────────────────────┐
                    │  PREMIUM TIER        │
                    │  หมอตี้, หมอบิ๊ก     │  ← แก้เคสซับซ้อน, 100K+
                    │  หมอเช, หมอโรส,     │
                    │  หมอวินน์, หมอจอร์เจีย│
                    ├─────────────────────┤
                    │  MID TIER            │
                    │  Endotine, Custom    │  ← High-value procedures
                    │  Implant, Deep Plane │     50K-90K
                    ├─────────────────────┤
                    │  ENTRY TIER          │
                    │  หมอตูน, หมอบอย     │  ← First-time, 12K-26K
                    └─────────────────────┘
```

### Key Insight: Doctor as Product Line

S45 ใช้หมอเป็น product line segmentation — แต่ละคนมี positioning, target group, และ pricing ที่ชัดเจน:
- หมอตี้ = brand flagship, ความเชื่อมั่นสูงสุด
- หมอบิ๊ก = โสต ศอ นาสิก เพิ่มมิติ functional medicine
- หมอตูน/หมอบอย = ตลาดล่าง ชิงส่วนแบ่งจากคู่แข่งระดับกลาง-ล่าง
- หมอปู้/หมอเจนนี่/หมอหยี = ขยายฐานลูกค้าสู่กลุ่มใหม่
