# Knowledge: เป้าหมายชีวิต

## แนวคิดหลัก (Core Idea)

> "เป้าหมายของมนุษย์ส่วนใหญ่คือความสุข → ความสุขส่วนใหญ่ใช้เงินซื้อ → เราต้องเอาความสามารถไปแลกเงิน → เราต้องเรียนรู้ ฝึกฝน ประสบการณ์ เพื่อเพิ่มความสามารถ → เราต้องเรียนที่ไหนกับใครก็แล้วแต่เพื่อมีความรู้"

## Story Angles

### Angle 1: ความสุข ≠ ไม่ต้องทำอะไร
- ความสุขไม่ใช่การนอนอยู่บ้านเฉยๆ
- ความสุขคือการมีอิสระในการเลือก
- อิสระต้องใช้เงินซื้อ (กินข้าวร้านนี้ได้ ไม่ต้องคิด, ไปเที่ยวได้, ซื้อของให้คนที่เรารัก)

### Angle 2: เงินคือเครื่องมือ ไม่ใช่เป้าหมาย
- เงินไม่ใช่ทุกอย่าง แต่มันเป็นเครื่องมือ
- เหมือนค้อน — ใช้สร้างบ้านก็ได้ ใช้ทุบหัวคนก็ได้
- อยากได้เงินต้องมีของแลก → ความสามารถ

### Angle 3: ความสามารถสร้างได้
- ไม่มีใครเกิดมาเก่ง
- ความสามารถ = ความรู้ × ประสบการณ์ × เวลา
- 3 ปัจจัยที่เพิ่มความสามารถ: เรียน, ฝึก, ทำซ้ำ

### Angle 4: เรียนจากใครก็ได้ จากอะไรก็ได้
- โลกคือห้องเรียน
- ทุกคนคือครู (แม้แต่คนที่เราคิดว่าไม่มีอะไรสอนเรา)
- ประสบการณ์คือข้อสอบ

## Script Ideas

| เรื่อง | Format | Hook |
|--------|--------|------|
| "พ่อเคยคิดว่าอยากรวย..." | Story time | "ลูกรู้มั้ย ว่าพ่อเคยคิดว่าอยากรวยที่สุดในโลก..." |
| เงินซื้อความสุขได้จริงมั้ย | Talking head | "มีคนบอกว่าเงินซื้อความสุขไม่ได้... พ่อว่ามันโกหก" |
| สิ่งเดียวที่เอาไปแลกเงินได้ | Quick tip | "ถ้าลูกไม่มีเงินเลยสักบาท มีอยู่สิ่งเดียวที่ลูกเอาไปแลกได้..." |
| โลกคือห้องเรียน | Story time | "พ่อเรียนตอนขับรถ เรียนตอนกินข้าว เรียนตอนฟังคนอื่น..." |
| เป้าหมายชีวิตของลูกคืออะไร | Talking head | "พ่อไม่ถามว่าลูกอยากเป็นอะไร แต่พ่อถามว่า..." |
| 3 ขั้นเพิ่มความสามารถ | Series E1-3 | "พ่อมีสูตรลับ 3 ข้อในการเก่งขึ้นทุกวัน..." |
| ทำไมเป้าหมาย = ความสุข | Talking head | "ทุกคนวิ่งหาความสุข แต่ไม่มีใครรู้ว่ามันอยู่ไหน..." |

## Key Messages

1. "ความสามารถคือสินทรัพย์เดียวที่ไม่มีใครขโมยไปจากเราได้"
2. "หาเงินเก่งแต่ไม่มีความสุข = ล้มเหลว / มีความสุขแต่หาเงินไม่เป็น = ลำบาก"
3. "อย่าถามว่าอยากเป็นอะไร — ถามว่าอยากมีความสุขแบบไหน"
4. "ทุกคนสอนเราได้ แม้แต่คนที่เดินผ่านเราใน 5 วิ"
5. "ความรู้ไม่มีน้ำหนัก แต่มีราคา"
