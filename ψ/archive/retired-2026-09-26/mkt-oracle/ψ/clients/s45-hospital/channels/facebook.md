# Facebook Channel — S45 Hospital

## Channel Strategy

Facebook คือช่องทางหลักสำหรับ **Community + Conversion** — กลุ่มเป้าหมายอายุ 25-45+ ที่ active บน Facebook และมีกำลังซื้อ

## Content Mix

| ประเภท | สัดส่วน | ตัวอย่าง |
|--------|---------|----------|
| Case Study / Review | 30% | รีวิวคนไข้ + Before/After ละเอียด |
| Promotion / Offer | 25% | โปรโมชั่นรายเดือน / Flash Deal |
| Educational Post | 20% | Infographic / ความรู้ศัลยกรรม |
| Live Q&A | 10% | หมอตี้ Live ตอบคำถาม |
| Brand Content | 10% | S45 Hospital preview / CSR |
| Community Engagement | 5% | คนไข้แชร์ประสบการณ์ |

## Facebook Ads Strategy

- **Objective**: Conversion + Lead Gen (LINE / แบบฟอร์ม)
- **Audience**: 
  - Interest: ศัลยกรรม, เสริมจมูก, ความงาม
  - Lookalike: จาก LINE OA / Website visitors
  - Retargeting: คนที่เคยดูเนื้อหาแต่ยังไม่ทัก
- **Creative**: Before/After carousel, Video review, Promotion graphic
- **Budget**: คาดการณ์หลักแสน/เดือน (ดูจากขนาดทีม + ROAS requirement)

## Key Features Used

- Facebook Live สำหรับ Q&A
- Messenger Auto-Reply → ส่งต่อไป LINE
- Facebook Shops / Services catalog
- Event สำหรับ S45 Hospital Grand Opening
