## 2. Key Influencer Campaigns & Cases

### 2.1 The Nisamanee Phenomenon (นัท นิสามณี)

การรีวิวแก้จมูกกับหมอตี้โดยนัท นิสามณี คือ **Masterclass ใน Influencer Marketing**:

| Element | Detail |
|---------|--------|
| **Influencer** | นัท นิสามณี — ยูทูปเบอร์/บิวตี้บล็อกเกอร์ระดับ Top ของไทย |
| **Platform** | YouTube (หลัก) + cross-post S45 channels |
| **Content** | รีวิว 4K: ปรึกษา → ดมยา → ผ่าตัด → พักฟื้น |
| **Psychological Impact** | 1) Global Standard Signal — คนระดับนี้เลือก S45 = มาตรฐานโลก 2) Absolute Transparency — ทุกขั้นตอนถ่ายให้ดู 3) Price Justification — คนรวยเลือก S45 แม้มีเงินไปที่ไหนก็ได้ |

### 2.2 Miss Grand Network

S45 สถาปนาตัวเป็นสถาบันเบื้องหลังวงการนางงามผ่านเครือข่าย Miss Grand:

- **Miss Grand 2022**: อิงฟ้า วราหะ, ชาลอต ออสติน
- **Miss Grand 2023**: อุ้ม พิมจิ, เทียร์, สแน็ค, เกด, ยุวเฟิร์น, มะปราง สุนทรี
- **Other Celebrities**: เอ็ม บุษราคัม (actress)

**กลยุทธ์**: Halo Effect Transfer — ความงามระดับประเทศ → S45 = สถาบันที่นางงามไว้วางใจ

### 2.3 Always-On Micro Influencers

- **Milky (มิ้วกี้)** — Beauty blogger, YouTube Shorts
- **Asoka Makeup** — Makeup artist, YouTube Shorts
- กลยุทธ์: ใช้คอนเทนต์สั้นหล่อเลี้ยงกระแสต่อเนื่อง ไม่ให้แบรนด์หายจากหน้าฟีด

## 3. Consumer Voice & Social Proof (จาก Gemini Research)

### 3.1 Wongnai (แพลตฟอร์มรีวิว)

| Metric | Value |
|--------|-------|
| **Rating** | 4.9/5 ดาว |
| **Total Reviews** | 85 ratings, 79 written reviews |
| **Ranking** | อันดับ 5 จาก 144 ร้านเสริมจมูกในกรุงเทพ |

**Key Insight**: รีวิวเป็นแบบ Longitudinal Assessment — ลูกค้ากลับมารายงานผลหลัง 6 เดือน, 7 เดือน, 2 ปี, 3 ปี:
- "Praewa" — รีวิวกระดูกอ่อนซี่โครงหมอตี้หลัง 3 ปี ยังสมบูรณ์
- "Ployy" — เสริมจมูกซี่โครงหมอโรสผ่านไป 2 ปี ทรงยังคมชัด ไม่หดรั้ง
- การมีรีวิวระยะยาวนี้หักล้างความกังวลเรื่องการใช้กระดูกซี่โครงได้อย่างทรงพลัง

### 3.2 Pantip & Lemon8

| Platform | Content Type | Key Mentions |
|----------|-------------|--------------|
| **Pantip** | กระทู้รีวิว, ถาม-ตอบ | เน้นความเป็นธรรมชาติ, แก้เคสซับซ้อน, หมอเก่ง |

### 3.3 Revision Case Psychology (Behavioral Economics)

จากรีวิวจริง — กลุ่มลูกค้า Revision:
- **Before S45**: "ปลายเอียง รูจมูกเบี้ยว ขาดความมั่นใจ ถ่ายหน้าตรงไม่ได้เลย" / "ติดเชื้อจนต้องถอดพัก"
- **After S45**: "รักคุณหมอที่สุด" / "จากจมูกพังกลายเป็นจมูกปัง" / "เก่งมากยืนหนึ่งเรื่องเคสยากปราบเซียน" / "พลิกชีวิตเลยจริงๆ"

**Psychological Mechanism**: S45 ไม่ได้แก้แค่จมูก — แต่แก้ Trauma และคืนความมั่นใจ → สร้าง Hyper-loyalty → Word-of-mouth ที่แข็งแกร่งที่สุด

## 4. Ads Architecture

### 4.1 Hybrid Ad Operations

```
GOOGLE ADS (ArioMarketing)
├─ Search: "เสริมจมูก" "แก้จมูก" "ยกคิ้ว"
├─ SEO: Content marketing, keywords
└─ YouTube: In-stream + Discovery

FACEBOOK/INSTAGRAM ADS (ArioMarketing + In-House)
├─ Campaign Objective: Conversion + Lead Gen
├─ Format: Carousel, Video, Collection
├─ Targeting: Interest + Lookalike + Retargeting
└─ Placement: Feed, Stories, Reels, In-Stream

TIKTOK ADS (In-House Ads Optimizer)
├─ Objective: Awareness + Traffic
├─ Format: In-Feed, Spark Ads
├─ Creative: UGC-style, Before/After
└─ Targeting: Interest + Behavior + Lookalike

LINE ADS
├─ Objective: Friend Add + Broadcast
├─ Format: Rich Message, Rich Video
└─ Targeting: LINE user data + Lookalike
```

### 4.2 Agency Mix

| Partner | Scope |
|---------|-------|
| **ArioMarketing** | Website, SEO, Google Ads, Facebook/IG Media Buying, Influencer Management |
| **แม่มณี ดิจิทัล เอเจนซี่** | Strategic Consulting |
| **In-House Team** | Ads Optimization (TikTok especially), Content Production, Community Management |

### 4.3 Strategy: ทำไมต้อง Hybrid

- **Agencies**: ความเชี่ยวชาญเชิงลึก, ประหยัดค่าใช้จ่ายการสร้างทีมใหม่, คงที่
- **In-House**: ความคล่องตัว ตอบสนอง algorithm changes รายวัน, ควบคุม creative ได้ใกล้ชิดกว่า
- **Balance**: Agency จัดการ macro strategy, In-house จัดการ micro execution

## 5. Key Insights

### Strengths
1. **Influencer Tiers สมบูรณ์** — Mega ถึง Nano, แต่ละระดับมีหน้าที่ชัดเจน
2. **Social Proof แข็งแกร่ง** — Wongnai 4.9, รีวิวระยะยาว 2-3 ปี, organic word-of-mouth
3. **Behavioral Economics เข้าใจลึก** — เล่นกับอารมณ์, สร้าง Savior archetype, แปลง Trauma เป็น Loyalty
4. **Hybrid Ad Ops** — Agency stability + In-house agility
5. **หมอตี้คือ Founder-KOL** — ไม่ต้องจ้าง, authentic, น่าเชื่อถือ

### Gaps
1. **Influencer program ไม่ต่อเนื่อง** — campaign bursts แต่ขาด always-on program
2. **Measurement framework ยังไม่ชัด** — focus ที่การหา influencer แต่ยังไม่เห็นระบบวัดผลชัดเจน
3. **International influencers** — ยังไม่มี program สำหรับ 15% ต่างชาติ
4. **Doctor team underleveraged** — มีแค่หมอตี้ที่เป็น KOL, ทีมแพทย์ 10 คนยังไม่ได้ใช้

## 6. Recommendations

### Influencer Program

| Priority | Action | Impact |
|----------|--------|--------|
| **High** | Micro-influencer always-on program (10-15 คน/เดือน) | Consistency + Continuous visibility |
| **High** | Doctor influencer training — สร้างหมอทุกคนให้เป็น KOL | เพิ่ม faces + voices |
| **High** | KPI Framework: Reach, Engagement, LINE add, Booking rate | วัดผลได้ |
| **Medium** | International influencer pilot — ASEAN, จีน | รองรับ S45 Hospital + 15% target |
| **Medium** | Patient ambassador program — คนไข้ revision ที่ประสบความสำเร็จ | Most authentic voice |
| **Low** | Nano-influencer referral program — จ่ายค่าคอมมิชชั่น | Scale UGC |

### Ads Optimization

| Priority | Action | Impact |
|----------|--------|--------|
| **High** | TikTok Spark Ads — boost influencer content | Higher engagement, authentic feel |
| **High** | LINE remarketing — retarget คนที่ add LINE แต่ยังไม่จอง | เพิ่ม conversion |
| **High** | Google long-tail: "แก้จมูกที่อื่นไม่รับ" "จมูกติดเชื้อ" | Capture high-intent revision |
| **Medium** | English ads pilot — ASEAN targeting | International pipeline |
| **Medium** | Doctor Q&A ad creative — หมอตอบคำถามใน ads | Educational + Authority |
| **Low** | YouTube bumper ads — 6s Before/After | Quick recall |
