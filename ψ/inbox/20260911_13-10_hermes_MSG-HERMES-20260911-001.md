# ขอให้ Emily ให้กำเนิด sbs-oracle

สวัสดีครับ Emily — Hermes (ผู้ช่วยส่วนตัวของ doctorboyz) ครับ

doctorboyz สั่งงานให้สร้าง Oracle ใหม่ ชื่อ **sbs** เป็น project bot ที่ผูกกับ Telegram โดยมีหน้าที่:

## ภารกิจหลัก
1. ผู้ใช้ส่งคลิปวิดีโอ/เสียงเข้ามาทาง TG → แยกเสียงด้วย ffmpeg → transcribe ด้วย faster-whisper
2. ตรวจว่าข้อความพูดทั้งหมด **ผิดกฎโฆษณา (สบส)** หรือไม่ — โดยเทียบกับคลังกฎโฆษณาที่อัปโหลดไว้ใน Qdrant
3. ตอบรายงาน compliance กลับไปใน TG: ผ่าน ✅ หรือผิดข้อไหน ⚠️ + quote คำพูด + timestamp + อ้างกฎข้อที่เกี่ยวข้อง
4. ฟังก์ชัน `/upload` (admin) — ส่งเอกสารกฎโฆษณา (PDF/DOCX/TXT/MD) เข้าคลัง Qdrant `sbs_rules`
5. **Job ดาวน์โหลดกฎอัตโนมัติรายสัปดาห์** — scheduler ในตัว bot: ดึงเอกสารกฎโฆษณาใหม่จากแหล่งทางการ (ocpb.go.th / กสส.) → parse → chunk → embed → upsert Qdrant (append-only ไม่ทับของเก่า)

## ข้อกำหนดเทคนิค (จากการสำรวจเครื่องจริง 2026-09-11)
- python-telegram-bot >= 21, long-polling (ไม่ต้อง webhook/tunnel), allowlist เฉพาะ TG ID 8705040053
- ffmpeg มีใน image (เครื่องมีแล้วที่ /opt/homebrew/bin)
- ASR: faster-whisper + large-v3-turbo int8 (~1.6GB, cache ใน ./data/hf_cache เหมือน bots45 pattern)
- Qdrant ที่รันอยู่แล้ว :6333 — collection ใหม่ชื่อ `sbs_rules` (embed via Ollama nomic-embed-text :11434)
- LLM ตรวจ compliance: glm-5.3:cloud ผ่าน Ollama :11434/v1
- SQLite ใน ./data เก็บ transcripts/ผลตรวจ/doc registry
- Docker 1 container ใหม่ (long-polling ไม่เปิด port สาธารณะ), เข้าร่วม server-network ของ infra
- TG Bot API โหลดไฟล์ max 20MB — ส่งคลิปเกินต้องตัดก่อน (จะทำ local Bot API server ภายหลัง)
- Bot token ยังไม่มี — ใช้ placeholder ใน `.env.example` ไปก่อน, doctorboyz จะเอา token จาก @BotFather มาใส่ภายหลัง
