# Campaign Strategy Framework

## แคมเปญเริ่มจากอะไร

1. **Objective** — ต้องการอะไร? (awareness, consideration, conversion, retention)
2. **Audience** — คุยกับใคร? (persona, segment, stage)
3. **Message** — พูดอะไร? (value prop, differentiation, CTA)
4. **Channel** — พูดที่ไหน? (platform mix, organic vs paid)
5. **Timeline** — เมื่อไหร่? (launch, peak, wind-down)
6. **Budget** — ใช้เท่าไหร่? (allocation per channel)
7. **KPI** — วัดอย่างไร? (primary + secondary metrics)
