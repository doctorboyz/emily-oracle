## Lessons Learned

### Lesson: maw wake all ใช้ fallback string ไม่ใช่ resolveOllamaModel
`maw wake all` (cmdWakeAll) ไม่ได้เรียก `resolveOllamaModel()` — ใช้ fallback string ใน `command-logic.ts` โดยตรง (ผ่าน getOllamaModelCache() || "fallback") ดังนั้นการเปลี่ยน default model ของ fleet wake ต้องแก้ fallback string ใน command-logic.ts ไม่ใช่แค่ command.ts

### Lesson: self-destructive command check
ก่อนรันคำสั่งที่กระทบหลาย session (เช่น `maw wake all --kill`) ต้องเช็คก่อนว่าคำสั่งนั้นจะ kill session ที่ตัวเองกำลังรันอยู่หรือไม่ — ใช้ detached execution (nohup) หรือ exclude self
