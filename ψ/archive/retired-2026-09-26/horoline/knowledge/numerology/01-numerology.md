# Numerology

## Life Path Number (เลขวิถีชีวิต)

**สูตร**: บวกเลขวัน+เดือน+ปีเกิด จนเหลือเลขเดียว (ยกเว้น Master Number 11, 22, 33)

```
ตัวอย่าง: 29 พฤศจิกายน 1987
เดือน: 11 → 1+1 = 2
วัน: 29 → 2+9 = 11 → 1+1 = 2
ปี: 1987 → 1+9+8+7 = 25 → 2+5 = 7
รวม: 2+2+7 = 11 (Master Number!)
```
