# Voice Learning #1 — ตัวตนจริงของ doctorpapaboyz

## Speaker Identity
- เรียกตัวเอง: **หมอ**
- เรียกผู้ฟัง: **คุณพ่อคุณแม่**
- เรียกเด็ก: **ลูกๆ**
- กลุ่มผู้ฟัง: พ่อแม่ที่มีลูกวัยประถม-วัยรุ่น

## หลักการที่ brand owner ยืนยันแล้ว
1. ไม่ใช่พ่อสอนลูก — แต่คือหมอแชร์ความรู้ให้พ่อแม่คนอื่น
2. ไม่หมกมุ่นเรื่องรวย — เรื่องเงินสอนให้รู้คุณค่า ไม่ใช่เร่งรวย
3. แก่นคือ "เป้าหมาย = ความสุข" — ไม่ใช่ "อยากรวย → อิสรภาพ"
4. ภาษาไทยธรรมชาติ มีหางเสียง "ครับ" — อบอุ่น เป็นกันเอง
