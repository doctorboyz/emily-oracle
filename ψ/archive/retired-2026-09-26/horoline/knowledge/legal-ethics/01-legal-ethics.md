# Legal & Ethical Compliance — กฎหมายและจริยธรรม

## PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562)

### ข้อมูลส่วนบุคคลที่ Horoline เก็บ

| ประเภท | ตัวอย่าง | ความจำเป็น | กฎ PDPA |
|--------|----------|-------------|---------|
| ระบุตัวตนได้ | ชื่อ, เบอร์โทร, LINE ID | ลงทะเบียน | ต้องได้รับความยินยอม |
| วันเกิด | วัน/เดือน/ปี, เวลา, สถานที่ | ทำนาย | ต้องได้รับความยินยอม |
| พฤติกรรม | การใช้แอป, คำถาม, การใช้จ่าย | ปรับปรุงบริการ | ต้องแจ้งวัตถุประสงค์ |
| ข้อมูลสุขภาพ | คำถามเกี่ยวกับสุขภาพ (ถ้ามี) | ไม่จำเป็น | **ห้ามเก็บโดยไม่จำเป็น** |

### สิทธิผู้ใช้ตาม PDPA

- **สิทธิรับทราบ**: แจ้งว่าเก็บอะไร ทำไม นานแค่ไหน
- **สิทธิเข้าถึง**: ผู้ใช้ขอดูข้อมูลตัวเองได้
- **สิทธิแก้ไข**: แก้ข้อมูลที่ผิดได้
- **สิทธิลบ**: ขอลบข้อมูลได้ (Right to be Forgotten)
- **สิทธิโอนย้าย**: นำข้อมูลไปที่อื่นได้ (Data Portability)
- **สิทธิคัดค้าน**: ปฏิเสธการใช้ข้อมูลเพื่อการตลาดได้

### การ implement PDPA

```typescript
interface ConsentRecord {
  userId: string
  consentType: 'registration' | 'prediction' | 'marketing' | 'analytics'
  granted: boolean
  grantedAt: Date | null
  revokedAt: Date | null
  version: string  // เวอร์ชันนโยบายความเป็นส่วนตัว
  method: 'explicit' | 'implicit'  // explicit = กดยอมรับ, implicit = ใช้ต่อเนื่อง
}

// หมายเหตุ: การเก็บข้อมูลวันเกิดเพื่อทำนาย ต้องมี consent แยกจากการลงทะเบียน
// ห้ามใช้ consent การลงทะเบียนครอบคลุมการเก็บข้อมูลทำนาย
```

## Consumer Protection (พ.ร.บ.คุ้มครองผู้บริโภค)

### ห้ามทำ

| พฤติกรรม | ตัวอย่างที่ห้าม | กฎหมาย |
|-----------|----------------|---------|
| หลอกลวง | "ดวงคุณจะแย่ถ้าไม่ซื้อ" | พ.ร.บ.คุ้มครองผู้บริโภค มาตรา 47 |
| ข่มขู่ | "คุณกำลังจะเจอเรื่องร้าย" | พ.ร.บ.คุ้มครองผู้บริโภค มาตรา 47 |
| โฆษณาเกินจริง | "แม่น 100%" | พ.ร.บ.คุ้มครองผู้บริโภค มาตรา 22 |
| บังคับข่มขู่ | "ต้องทำพิธีกรรมนี้เท่านั้น" | ประมวลกฎหมายอาญา มาตรา 309 |
| ไม่ให้ข้อมูล | ไม่แจ้งราคา ไม่แจ้งเงื่อนไข | พ.ร.บ.คุ้มครองผู้บริโภค มาตรา 34 |

### สิทธิผู้บริโภคที่ต้องมี

1. **สิทธิรู้**: รู้ว่าบริการคืออะไร ราคาเท่าไร เงื่อนไขอะไร
2. **สิทธิเลือก**: เลือกได้ว่าจะใช้หรือไม่ ไม่ถูกบังคับ
3. **สิทธิร้องเรียน**: ร้องเรียนได้ถ้าบริการไม่เป็นที่พอใจ
4. **สิทธิคืนสินค้า**: คืนเงินได้ถ้าบริการไม่เป็นไปตามที่โฆษณา

## Disclaimer (ข้อจำกัดความรับผิดชอบ)

### ที่ต้องแสดงทุกครั้ง

```
⚠️ คำทำนายเป็นการตีความจากตำราโหราศาสตร์ เพื่อการบันเทิงและการสะท้อนตนเองเท่านั้น
ไม่ใช่คำแนะนำทางการแพทย์ การเงิน หรือกฎหมาย
การตัดสินใจสำคัญควรปรึกษาผู้เชี่ยวชาญ
```

### เมื่อกล่าวถึงสุขภาพ/การเงิน

```
⚠️ หมายเหตุ: ข้อมูลนี้ไม่ใช่คำแนะนำทางการแพทย์/การเงิน
หากมีข้อกังวล กรุณาปรึกษาแพทย์/ที่ปรึกษาการเงิน
```

### ใน Premium/Tier พิเศษ

```
ผลการทำนายขึ้นอยู่กับข้อมูลที่คุณให้ และการตีความอาจแตกต่างไปตามระบบและผู้ตีความ
ผลลัพธ์ไม่ได้รับประกันความแม่นยำ
```

## Age Gate (การควบคุมอายุ)

### กฎหมายไทย

- **อายุต่ำกว่า 13 ปี**: ห้ามใช้บริการโดยไม่ได้รับความยินยอมจากผู้ปกครอง (PDPA)
- **อายุ 13-17 ปี**: ใช้ได้แต่ต้องมีความยินยอมจากผู้ปกครอง
- **อายุ 18 ปีขึ้นไป**: ใช้ได้เต็มรูปแบบ

### Implementation

```typescript
interface AgeGate {
  minimumAge: 13            // ห้ามต่ำกว่านี้
  restrictedAge: 18         // ต้องมี consent เพิ่มเติม
  premiumMinimumAge: 18     // ซื้อ premium ต้อง 18+
  parentalConsentRequired: true  // อายุ 13-17 ต้องมี
  verificationMethod: 'self_declaration' | 'id_verification'  // ขั้นตอนยืนยัน
}
```

### เนื้อหาที่จำกัดอายุ

| เนื้อหา | อายุขั้นต่ำ | เหตุผล |
|---------|-------------|--------|
| ทำนายทั่วไป | 13 | เข้าใจได้ว่าเป็นการบันเทิง |
| ทำนายเชิงลึก | 15 | ต้องมีความเข้าใจมากขึ้น |
| Premium/ซื้อเครดิต | 18 | กฎหมายคุ้มครองผู้บริโภค |
| ทำนายเกี่ยวกับการเงิน | 18 | ต้องมีความรับผิดชอบ |
| ทำนายเกี่ยวกับสุขภาพ | 18 | ต้องปรึกษาแพทย์เท่านั้น |

## Advertising Ethics (จริยธรรมการโฆษณา)

### หลักการ

1. **เป็นจริง**: ไม่โฆษณาเกินจริง เช่น ห้ามบอกว่า "แม่น 100%"
2. **ไม่กดดัน**: ไม่ใช้ fear-based marketing เช่น "ดวงจะแย่ถ้าไม่..."
3. **โปร่งใส**: แจ้งราคา เงื่อนไข และข้อจำกัดอย่างชัดเจน
4. **เคารพ**: ไม่ใช้ความเชื่อด้อย ความกลัว หรือความอ่อนแอเป็นเครื่องมือขาย
5. **รับผิดชอบ**: มีช่องทางร้องเรียน คืนเงิน แก้ไขปัญหา

### ห้ามทำในโฆษณา

| ห้าม | ตัวอย่าง | ทำไม |
|------|---------|-------|
| Fear-based | "ดวงจะแย่ถ้าไม่ทำนาย" | ใช้ความกลัวขาย |
| False precision | "แม่น 99.9%" | ทำนายไม่ได้แม่นขนาดนั้น |
| Urgency/FOMO | "เหลือ 3 ที่นั่งเท่านั้น!" | สร้างความเร่งรีบเทียม |
| Authority claim | "โหราจารย์ระดับประเทศ" | อ้างตำแหน่งโดยไม่มีหลักฐาน |
| Dependency creation | "ต้องทำนายทุกวันถึงจะปลอดภัย" | สร้างความพึ่งพา |

## Implementation Checklist

- [ ] PDPA consent flow ครบทุก consentType
- [ ] Age gate ที่หน้าแรก (self-declaration + optional ID verification)
- [ ] Disclaimer แสดงทุกครั้งที่ทำนาย
- [ ] Disclaimer เพิ่มเติมเมื่อกล่าวถึงสุขภาพ/การเงิน
- [ ] ช่องทางร้องเรียน + คืนเงิน
- [ ] ไม่มี fear-based, FOMO, false precision ใน copy
- [ ] สิทธิผู้ใช้ PDPA ทั้งหมด implement ครบ
- [ ] Data retention policy กำหนดระยะเก็บข้อมูล
- [ ] ผู้ปกครอง consent flow สำหรับอายุ 13-17
