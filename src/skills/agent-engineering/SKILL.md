# Agent Engineering

This skill unifies agent design, tool construction, and debugging into a single workflow.

## 1. Agent Architecture
- Use `agent-architect` patterns (Sequential, Coordinated, Orchestrator/Workers).
- Define clear boundaries and responsibilities for each sub-agent.

## 2. Harness Construction
- Design toolsets with clear schemas (JSON/Zod).
- Ensure observation formatting is LLM-friendly.

## 3. Introspection & Debugging
- Use self-debugging loops for agent failures.
- Analyze tool traces to identify logic gaps.
